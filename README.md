# Kirthik & Nikkila — The Wedding Comic 💍

A complete anime-comic wedding invitation, including a **six-scene illustrated true love story** (from the first phone call on May 24, 2026, to the upcoming first meeting and wedding), tappable floating hearts, the funny “Wake Up, Kirthik!” interaction, the wedding schedule, interactive flower showers, live countdown, map, and WhatsApp sharing.

## Publish free on GitHub Pages

1. Sign in to GitHub as **KirthikRoshan**.
2. Create a new **public repository** called `comic_wedding` (exact spelling).
3. Upload **all files from this ZIP directly to the repository's main folder** using **Add file → Upload files**. Do not upload the ZIP itself, and do not put the files in another folder.
4. Commit the upload.
5. Open **Settings → Pages**. Under **Build and deployment**, select **Deploy from a branch**, choose **main** and **/(root)**, and save.
6. Wait a few minutes, then visit <https://kirthikroshan.github.io/comic_wedding/>.

All of the artwork, **six new chapter illustrations**, images, calendar files, HTML story content, CSS and JavaScript are included. The image paths are designed to work in the repository's root folder. Keep `story-chapters.html`, `story.css`, and `story.js` alongside `index.html`—they are needed for the story reader.

The WhatsApp button shares the current page URL automatically. `README.md` and `.nojekyll` are not part of the visible invitation.
